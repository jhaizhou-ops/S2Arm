Goal: get into actual gameplay and directly control the character. If there is a save with progress, load it (Continue / Load; on a save-select screen pick the slot that shows progress, stars, play time or a name, not an empty slot). Start a new game only when there is no save at all (a new game plays a long opening story).
Playable means: a controllable character or vehicle is in the game world (a HUD may be shown). Menus, title screens, level / character select, cutscenes, loading screens, a dialog box covering the screen, and pause screens (dimmed or blurred with PAUSE text or a pause menu) are not playable. When playable, do not answer PLUS / MINUS. A save / file-select slot card (slot number like 01 / FILE 1, saved play time like 00:02:54, health / ammo / energy numbers, difficulty like NORMAL MODE, completion or ITEMS %, area name) on an otherwise empty or menu background is NOT a HUD and NOT playable: press A to load that slot; a real HUD sits over a visible game world with the character in it.
Never open shops, DLC / add-on content, settings / options, online / network features, and never delete or overwrite saves. Close popups with confirm.
Menus where the highlighted item is not visibly marked (all entries look the same): assume the first entry (usually Continue / 继续) is selected and press A without moving; never press DOWN to "reach" Continue. Never choose Master Mode / Hard / Expert / harder-difficulty variants of a game mode, or "purchased content / 已购买的新增内容" entries.
No save: if a Continue / Load screen says there is no save data (e.g. "No save data", 未找到存档, 没有存档数据), there is no save this run: go back to the title and choose New Game / Start from the beginning. But a save-slot list where every slot is empty or says New Game (often reached from Start / New Game) is a creation page: press A on the first empty slot, do not go back.
Creation pages (create a character / world / save, an empty save slot list such as "choose a file to save to", an empty name field): never press B to go back. On an empty slot press A to create. If the button legend at the bottom shows a Create / Confirm key, press that key (legend "(X) Create" means press X). If a name field is empty, first move the cursor to it and press A to open the keyboard; on the keyboard accept the default name or press OK / + (if the default name is rejected, move to OK and press A); back on the creation page press the legend's Create / Confirm key.
Multi-page agreements / notices (a page counter like 1/22): page forward with the next-page key the on-screen legend shows (a ▼ / ↓ legend means DOWN, a ▶ / → legend means RIGHT, an R / ZR legend means R / ZR; with no legend try R / ZR, the right stick, then DOWN) to the last page, then press the key the legend binds to Agree / 同意 / Accept (legend "+ 同意" or "(+) Accept" means PLUS; never the Disagree key such as "- 不同意"); only if the legend shows no Agree key, move the cursor onto Agree (not Disagree) and press A. Do not keep trying single keys on the first page. A long text with a scrollbar whose Done / OK does nothing on A: scroll to the bottom first (hold the right stick down RS_DOWN:3, or DOWN:3), then press A.
Yes / No confirmations (はい / いいえ, Yes / No, 是 / 否, OK / Cancel): first check which option is highlighted. Many games default to No, and pressing A then just closes the box. Move the cursor to the option you want before pressing A (e.g. LEFT then A). When it asks to delete / overwrite a save, choose No. If a d-pad direction (UP / DOWN / LEFT / RIGHT) is listed as already tried without effect and the cursor is still on the wrong option, the menu probably reads the left stick only: answer the same direction on the left stick (LS_UP / LS_DOWN / LS_LEFT / LS_RIGHT) followed by A.
Read the on-screen button legend first (usually in a corner or at the bottom, e.g. "(X) Start", "L Insert coin", "+ Skip"): prefer the keys it shows, especially X / Y / L / R / + / d-pad keys not tried yet. In a four-dot button icon the lit dot means: top = X, right = A, bottom = B, left = Y. A button icon drawn inside or next to the focused / highlighted item (e.g. a "(Y)" bubble on the selected link or checkbox) is the key that activates that item: press that key, not A (A usually belongs to the dialog's own "(A) Agree / OK" button). Agreement dialogs with an unticked checkbox and a greyed-out Agree / OK: the checkbox must be ticked first. If the focus highlight is not on the checkbox (e.g. it is on a link above it), move it there with DOWN (answer only DOWN this turn); when the focus is on the checkbox, press the key shown in its focus bubble (often Y); once it is ticked, press A for Agree. An empty circle / box means NOT ticked (a ticked one shows a check mark or filled dot) — do not assume it is ticked. If the checkbox stays empty after pressing its key, the game wants the linked documents opened first: move the focus up to each link (UP), press the key in its focus bubble to open it, close it with B, do this for every link, then go back down to the checkbox and tick it.
Story cutscenes / opening movies (no HUD, characters talking or the camera moving by itself): press PLUS to skip (most Switch games then ask "Skip?" — confirm with A); do not keep pressing A to watch. If + only shows PAUSE, press + again to close it and hold X instead (X:2), then try holding B or A.
Touch: when the screen explicitly asks you to touch (e.g. "touch the screen", "use touch in handheld mode"), or options are chosen with a hand pointer / cursor that the d-pad cannot move, answer TOUCH at the position to tap. This takes priority: if the screen asks to touch, touch even if a hand pointer is shown. Use the d-pad / left stick only for cursor menus the d-pad can move.
Two-player co-op (Player 2 / 2P joins, gets ready, or both pick characters): prefix a key with 2: to press it only on the second controller (2:A to join / confirm, 2:RIGHT to move player two's cursor). As soon as Player 2 / 2P / Join / "press A to join" appears, answer 2:A first. After the second controller is connected, unprefixed keys press only controller one. If both selection frames sit on the same character, move only player two toward the free side (e.g. 2:LEFT), then confirm with A and 2:A.
