# 安卓追平 iOS：玩家可见的差距表

目标：安卓端达到目前 iOS 端同等质量。这张表从「玩家拿到手能不能用」的角度列差距，和 #48（安卓直连技术总表，按批列性能与缺陷）互补：#48 管每一项怎么做，这里管做完以后玩家那一侧还差什么。进度在总进度 PR 里勾选，认领以 #48 和该 PR 里维护方的确认为准。

基线：main `a1231620`（2026-11-10 晚）。「安卓现状」每一格都对过这个提交的代码或当天的真机局；没核的写「未核」。

## 直连起局：今天收掉的五处

同一台骁龙 8 Elite 手机、同一款 SDK 10 以前的 2D 游戏，显式直连，一处一处往前推。每一处都是一类游戏的起局拦路点。

| # | 停在哪 | 原因 | 修复 |
|---|---|---|---|
| 1 | 起局 2 秒，引擎断言 NVN API 主版本 | 读游戏自带驱动版本的强定义只在苹果专属文件里，安卓一律报 55.x | #548（已合） |
| 2 | `op=31` 拷贝带视图 / 偏移 | 安卓回放只认整张 2D mip0 | #537 ha7rock（已合） |
| 3 | `op=31` 拷贝带 flags | 1:1 拷贝里两个标志不改变结果，却被拒 | 随 #537 合入时补（已合） |
| 4 | 首笔 draw 编译请求缺 `samplerArrayLength` | 每次提交都把回放状态清零，Metal 只清第一次 | #547（已合，#539 第 1 点） |
| 5 | 约 640 帧后 `op=10` 清除 | 纯深度目标上带模板位清除被当成不支持 | #547（已合） |

## 怎么认领

- 表里「待认领」的项，在总进度 PR 或 #48 里回一句要做哪一项；一个 PR 只做一件事，写 `Part of #48`。
- 没有真机也能做：大多数项可以在宿主上做红绿。真机读数请写明机型、SoC、系统版本、是否接电。
- 约束见 [AGENTS.md](AGENTS.md)：安卓只做直连，新能力优先做到共用层，先查 [安卓接入矩阵](../docs/安卓接入矩阵.md) 接现成的共用件。
