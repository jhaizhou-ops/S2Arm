# generic 编译事件诊断

只覆盖安卓 generic 图形路径；须使用调试构建并同时打开 `debug.s2a.debug_env=1`、`debug.s2a.frame_log=1`。开关关闭时不建事件文件。生产者在 GPU 启动前按会话初始化，GPU 停止且在途事件全部结束后封口。异常退出或无法排空时，不以残留文件推断零现编。

会话私有状态目录的 `compile-events-<pid>.jsonl` 使用 `s2a-compile-events-v2`：首行是进程、session、`CLOCK_BOOTTIME`、采集起点和容量；中间每行是递增事件号、类型、结果和同一时钟的起止微秒；尾行是状态、数量、丢失数、全会话着色器命中累计数、采集终点和 SHA-256。命中仅计数，不占逐条事件槽；该累计数覆盖整次会话，不能当某个局部窗口的命中数。哈希覆盖首行、中间行以及尾部除哈希字段外的规范化字段。默认容量 16384，可在开局前以 `debug.s2a.compile_cap` 设置 1–65536，非法值使采集初始化失败；关闭调试门时不生效。只要丢失数非零、文件截断、时钟/身份不符或未覆盖指定窗口，整段未证。读取器仍接受旧的 v1 文件；v1 的命中是逐条记录，不能把缺失的 v2 累计数当零。

- `translation` 一条表示一次着色器请求，从进入缓存查找至命中返回，或至解码、翻译及宿主 program 创建完成；`hit` 表示请求命中缓存（仅汇总计数），`miss` 表示缓存未命中并完成翻译，`failure` 表示请求异常退出。时间包含该请求的查找和创建开销，并非纯翻译器 CPU 时间。
- `graphics_pipeline` / `compute_pipeline` 覆盖相应 `vkCreate*Pipelines` 调用。成功返回记 `miss`，表示进入了创建路径，并不证明 Vulkan 驱动内部缓存未命中；失败记 `failure`。这些是 CPU 墙钟区间，不是 GPU 执行时间。

设备测试经 devrun 的 `private_files: ["compile_events"]` 请求，读取前核对 debug 身份；run-as 只读抓取后验证文件稳定性、完整性、READY PID / 会话 / boot 和 READY→结束窗口。完整记录只证明覆盖和事件；请求失败、缺片、缓存命中无法验证或时钟不匹配不能被当作「首遇现编 0」。事件记录本身也会扰动调试局，不能替代真实性能 A/B 或证明长帧因果。
