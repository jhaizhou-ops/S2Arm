# Android完整颜色清屏实验

## 版本与范围

基线为`4808439c`，包含`android/integration@cbacdf8b`。先安装未加本实验的v15，
再基于相同最新代码构建v16作同APK开关对照；本轮不混入之后的远端更新。
v16 APK SHA256：`8ea3b6c864d46beb852c04d78d9241a114d42d8b495bd9b0449d23ff90e88e4c`。
朱4.0.0、小米17/API36/4KiB/原厂Adreno840。资源仍为743文件、根
`6ab0aaea1398c7f3a4b0a875173716f4391cf33a99a738dfba16d400ac557941`，未改游戏代码、
分辨率、时钟、交换间隔或存档。游戏实际请求仍为2/60秒。

## 机制

原高通兼容路径用辅助绘制代替`CmdClearAttachments`，每次先提交主命令缓冲，
再租用并提交独立helper命令缓冲。此前两组160个GPU线程墙钟样本中，该路径分别
77/160、49/160；栅栏等待49/160、39/160。不能将墙钟样本直接当GPU执行耗时。

最初“无活动查询时借主CB绘制”的候选没有保留：持续查询限制适用范围，v12两局
18.37/20.37次present每秒还有缓存/分配差异，不能证明收益。
第二步仅覆盖RGBA8/BGRA8 UNORM，v13同页30秒为20.77→21.90次/秒，P95
58.03→58.46ms；未认定稳定改善。受控诊断随后实际记录到HDR、sRGB、R8、RG16
等格式仍走辅助绘制，按这些实际输入补驱动探针后扩展到8种格式。

生产入口：`PipelineFull.TryClearColorByTransfer`，Ryujinx补丁`0259`。
只接管经过验证的完整、全通道、基准mip、单层非MSAA 2D颜色清除，要求存储与视图
的格式/尺寸相同、usage和格式能力允许transfer-dst、裁剪覆盖整图。条件渲染、
部分通道/裁剪、3D、数组、其他格式和深度/模板保持原实现。
结束原渲染遍并落实屏障后，在原主CB记录`ClearColorImage`，前后依赖均显式保留，
image引用随该CB完成退休。待处理查询仍及时提交，每64次清除也提交，避免无界录制。
没有删除高通兼容分支、跳过绘制、放松保护或吞驱动错误。

Android冷启动读取`<state>/vulkan-transfer-clears.enable`，缺省关闭。
其他前端未设置此选项，Metal代码没有改动；不将Android设备验证推广为Apple真机验证。
用于定位未命中条件的日志最多记录8种格式/掩码组合，不逐帧写日志。

## 验证

- 69项真实生产方法切片的分支/顺序检查通过；旧源码在行为断言失败。
  13种破坏性对照均编译成功、运行失败，含掩码、裁剪、格式、权限能力、条件渲染、
  查询进度、录制上限与重置、屏障、实际清除和颜色原始位模式。
- 独立驱动探针：8格式×128组×96×80，共7864320像素；原厂Adreno840，
  driverVersion=2150932524，超容差像素0，精确遮挡查询错误0。
  UNORM/SRGB/SNORM按1 LSB容差，其余精确位模式；含0.5线性→sRGB、负SNORM、
  半浮点/packed-float和UINT。遗漏清除负控退出1，每格式974848像素错误。
- Android生产背后内存变更握手290项通过，metrics写出器/成功present接线及其负控通过。
  同步修复两处测试夹具与上游诊断代码/Foreground接口的边界漂移，未改生产metrics口径。
- v16本机NativeAOT、APK构建、签名、16KiB对齐、lint通过；安装回读SHA与本地产物一致。
  253个Ryujinx补丁重放一致。没有执行完整仓库门禁或Vulkan验证层。

## 真机读数口径

v16开关对照恢复同一磁盘缓存快照，SHA256
`60592c2d2c5abfd9d7d8edd8e0f210b0d8b6ebd238459b567f5e9414a3cec74c`。
原存档保留，前轮缓存重命名保留。固定形象选择页、无输入，每窗30秒。
按真实CLOCK_BOOTTIME和成功queue-present返回计数；采样窗内无截图或ptrace。
两边均开启相同逐帧同步文件采集，开销未扣除；不是物理扫描帧率、GPU计时或正式关卡验收。
手机在充电，不据此判断3.7W能耗。原始资源、日志、存档、APK与截图只留本地。

### v16 同包结果

每个设置1局、每局完整30秒操作静止窗；相邻帧索引与CLOCK_BOOTTIME差逐行核对通过。
两局启动前ADB连接均短暂中断，恢复后重新核对APK和开关，再启动采样；未把准备阶段
混入窗口。两边电池服务均报告AC供电，采样前电池温度31.1/31.4°C；不是CPU/GPU温度。

也没有同页关闭/开启对照可据以证明其根因。没有实际关卡、长时间稳定性或功耗结论，分配量
也仍高于项目稳态目标。此前GPFIFO/读回保护失败不因此视为解决。
