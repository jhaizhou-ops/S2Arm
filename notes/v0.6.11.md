# S2Arm v0.6.11

这一版主修闪退和画面：iPhone / iPad 上内存地址不够导致的一类中途闪退、即时存档越存越大后的中止、上一局闪退后下一局变得很卡，都已修；部分社区补丁导致的闪退、部分 GL 游戏整屏粉红也已修。新场景首次加载的卡顿和开场闪黑减少；Mac 上 Joy-Con 2 连不上时会提示原因。
*This release mainly fixes crashes and graphics: on iPhone / iPad, a class of mid-game crashes caused by running out of address space, aborts after the snapshot grows too large, and heavy slowdowns in the session after a crash are fixed; crashes caused by some community patches and the all-pink screen in some GL games are fixed too. Stutter when first loading a new scene and black flashes at the start are reduced; on Mac, a Joy-Con 2 that cannot connect now explains why.*

## 新增
- **Mac 键位管理**：键位弹窗里可以导入 / 导出键位，设为所有游戏的默认，点保存才生效；默认文件坏了会提示，不再静默退回标准键位（#1987，感谢 ChuBL）。
  *Mac key mapping management: the key mapping dialog can import / export mappings and set them as the default for all games, applied when you press Save; a damaged default file is reported instead of silently falling back to the standard layout (#1987, thanks to ChuBL).*
- **iOS 游戏内设置加了声音两项**（静音模式下也播放声音、与其他 App 混音）；导出的按键布局带上按键外观；有可见 LS / RS 键时浮动摇杆不再当成 LS / RS 按下（#2303）。
  *In-game settings on iOS gain the two sound options (play sound in Silent Mode, mix with other apps); exported button layouts include button appearance; with visible LS / RS buttons, floating sticks no longer press LS / RS (#2303).*
- **Mac 接管 Switch 2 游戏的 H.264 硬件编码**（感谢 kurtzou1）。
  *Mac handles H.264 hardware encoding for Switch 2 games (thanks to kurtzou1).*
- **Mac 上 Joy-Con 2 连接**：连接过程写进诊断包；Switch 2 主机开着或休眠时会把手柄抢回去，「没找到 / 唤醒别的主机 / 断开」三处提示都会说明，先彻底关机或拿远（#2318，感谢 cxyxlxdm 查到根因）。
  *Joy-Con 2 on Mac: the connection log is included in diagnostic packages; when a Switch 2 console that is on or asleep takes the controller back, the "not found / waking another console / disconnected" notices say so and suggest turning the console fully off or moving it away (#2318, thanks to cxyxlxdm for finding the cause).*
- **土耳其语 README**（感谢 Burakceliks）。
  *Turkish README (thanks to Burakceliks).*

## 修复
- **iPhone / iPad 内存地址不够导致的中途闪退**：图形管线占用按设备剩余的低区地址封顶，预热到线就停（#2020）。
  *Mid-game crashes on iPhone / iPad from running out of low address space: graphics pipeline usage is capped by the address space left on the device, and warm-up stops at the limit (#2020).*
- **开着即时存档玩久了中止**：几类系统服务的请求不再一直记进即时存档的请求日志，日志不再涨到上限后中止（#1369）。
  *Aborts after playing long with snapshots on: requests to several system services are no longer kept in the snapshot request log, so it no longer grows to the limit and aborts (#1369).*
- **上一局在前台闪退后，下一局整局很卡**：不再因此把整段游戏内存改放到文件里（#1268）。
  *A whole session running very slowly after the previous one crashed in the foreground: game memory is no longer moved to a file because of it (#1268).*
- **部分社区补丁（代码洞写法）导致的闪退**，如一款大型 3D 游戏的宽屏补丁转横屏就闪退；需重新出包生效（#2301）。
  *Crashes caused by some community patches that use code caves, such as a widescreen patch for a large 3D game crashing on rotating to landscape; rebuild the game for this to take effect (#2301).*
- **满屏开关显示的状态与实际一致**（#2205）。
  *The full-screen switch shows the state that is actually used (#2205).*
- **部分 GL 游戏进游戏整屏粉红**：着色器里多余的分号不再让整支着色器编不出来；不用重新出包，设备上会自动重新翻译（#2304）。
  *An all-pink screen in some GL games: a stray semicolon no longer makes the whole shader fail; no rebuild needed, the device retranslates it automatically (#2304).*
- **冷启动不再全量预建冷贴图**，开场黑闪和内存占用回到原先的水平（#2269，感谢 judeyang）；按上次真正读过的贴图预建，首帧闪黑减少（#2306，感谢 judeyang）；新场景大量建贴图时的卡顿减少（#2299，感谢 judeyang）。
  *Cold starts no longer prebuild every cold texture, bringing start-up black flashes and memory use back to their earlier level (#2269, thanks to judeyang); textures that were actually read last time are prebuilt, reducing first-frame black flashes (#2306, thanks to judeyang); stutter when a new scene builds many textures is reduced (#2299, thanks to judeyang).*
- **加载页的游戏名与游戏库封面一致**；横屏冷启动后点封面能正常起局（#502）。
  *The game name on the loading page matches the library cover; tapping a cover after a cold start in landscape starts the game (#502).*
- **游戏内「主机模式」开关如实显示**被社区满屏补丁强制打开的那一局（#2303）。
  *The in-game "Docked mode" switch correctly shows sessions where a community full-screen patch forces it on (#2303).*
- **手柄与体感**：iOS 上手柄分到玩家位就打开体感传感器、断开才关，回到前台补开，不再随游戏要不要体感反复开关（#2142）；Joy-Con 写给游戏的体感方向统一（#2287，感谢 nevenhsu）；新接入的手柄占最小的空位、出厂摇杆校准不再随读数扩大（感谢 kurtzou1）；Mac 上北通鲲鹏 20 的接收器和有线模式双摇杆可用（#2302，感谢 eateeer）。
  *Controllers and motion: on iOS, a controller's motion sensors turn on when it gets a player slot and off only when it disconnects, and turn back on when returning to the foreground, instead of toggling with each game request (#2142); Joy-Con motion direction sent to games is unified (#2287, thanks to nevenhsu); a newly connected controller takes the lowest free slot and factory stick calibration no longer widens with readings (thanks to kurtzou1); on Mac, both sticks of the Betop Kunpeng 20 work through its receiver and in wired mode (#2302, thanks to eateeer).*
- **声音**：卡顿后多出来的待播声音能排掉，不再一直滞后（#2300，感谢 nevenhsu）；混音器工作缓冲固定后不再因内存整理闪退（#2291，感谢 nevenhsu）；开场 AV1 影片声音不再跑在画面前面（#2242，感谢 nevenhsu）。
  *Audio: extra queued audio after a hitch drains instead of staying behind (#2300, thanks to nevenhsu); the mixer's work buffer is pinned so memory compaction no longer crashes it (#2291, thanks to nevenhsu); sound in AV1 intro movies no longer runs ahead of the picture (#2242, thanks to nevenhsu).*
- **签名证书导入**：base64 文本的 .p12 先解码；系统解不开时给一次输入密码的机会。
  *Certificate import: a .p12 given as base64 text is decoded first; if the system cannot open it, you get one chance to enter the password.*
- **Mac**：后台启动或上次关掉窗口后再打开时，主窗口照常出来；分享金手指的确认弹窗在 macOS 26 / 27 上不再按钮空白（感谢 judeyang）。
  *Mac: the main window appears when the app starts in the background or after its window was closed last time; the confirmation dialog for sharing cheats no longer shows blank buttons on macOS 26 / 27 (thanks to judeyang).*
- **画面**：Metal 上地形着色器按动态索引取贴图时不再取错材质（感谢 IF-Lawrence）；短常量缓冲越界读补零（感谢 Exynos-8890）；只测深度绘制的自遮挡暗点修正（感谢 nevenhsu）；多款游戏的着色器与绘制修正（感谢 Ting2024、judeyang）。
  *Graphics: terrain shaders on Metal no longer pick the wrong material when indexing textures dynamically (thanks to IF-Lawrence); out-of-range reads of short constant buffers return zero (thanks to Exynos-8890); dark self-shadowing spots in depth-only draws are fixed (thanks to nevenhsu); shader and draw fixes for several games (thanks to Ting2024 and judeyang).*
- **安卓直连**：支持细分着色器；几何着色器图元按游戏顶点顺序装配；交换链按屏幕方向预旋转；贴图上传、预编库、查询与透明混合等多处修正和提速（感谢 n06ody、WKkCoder、Ting2024）。
  *Android direct path: tessellation shaders are supported; geometry shader primitives are assembled in the game's vertex order; the swapchain is pre-rotated to the screen orientation; many fixes and speed-ups to texture uploads, prebuilt libraries, queries and transparent blending (thanks to n06ody, WKkCoder and Ting2024).*
