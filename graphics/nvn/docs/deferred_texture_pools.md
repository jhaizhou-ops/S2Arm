# 延迟纹理绑定的描述符池偏移（#270 E 组）

`nvnCommandBufferBindTexturesDeferred` 已有入口，却在非首个描述符池下丢掉池的宿主编号偏移。录制时原代码借用普通绑定的复制与重编号；回放 `bh_fresh` 又用源地址处的原始句柄覆盖结果，因此纹理和采样器都可能落到首池的同号资源。原代码对此打印 `numbering base of this command buffer's bound descriptor pools is not added`。

本次仅修复该入口。其余五个 `Bind*Deferred`、曲面细分与变换反馈不在范围内，函数签名、对象布局及普通绑定行为不变。

## 依据与状态合同

- 自有惊奇 1.2.1 SDK 的入口 `0x469e60` 保存第五参数指针，录制过程不解引用源数组。SDK SHA-256：`73bec5989030d4d9f056503066180a6100bb7937370a4d818c8ba53960dfa2f3`。怪猎 SDK 没有该名称，不作为第二份 ABI 核准证据。
- 现有静态普查：旷野之息 1、惊奇 8、王国之泪 30 个函数槽读取点。这是启发式静态读取统计，不是动态调用或故障复现。
- 描述符注册沿用生产池表的独立编号：纹理号占句柄低 20 位，采样器号从第 20 位起。每个非零分量加对应池的基址；零分量维持零。
- 延迟绑定录制时保存源地址与当前命令缓冲已绑定的两个池基址；回放时读取源值后再重编号。源数组仍由调用者负责保持有效并同步，不复制为录制时快照。
- 仅延迟记录在有效句柄数组 `h[n]` 后增加 8 字节 `{tbase, sbase}`。普通数组绑定和单纹理绑定的记录大小、布局均不变。每次刷新从原始源值开始，重复提交或预扫不会累加池偏移。
- 回放状态更新、资源预扫、遍合并等现有读取者继续共用 `bh_fresh`。测试动态覆盖队列状态回放；各预扫分支只做调用路径审查，未声称全部动态覆盖。

这一修复沿用普通绑定既有的「录制时命令缓冲池状态」策略；未绑定池而依赖队列继承、子命令改变外部池状态等更广的语义不在本次结论内。

## 可公开重跑的生产 API 测试

```sh
make native-test-nvn_a native-test-nvn_e
```

E 组经完整生产 bootstrap、注册节、跳板、真实 Device / MemoryPool / 描述符池 / CommandBuffer / QueueSubmitCommands / QueueFinish，不提供替身或测试专用访问器。仅从调用者自己的命令内存读取记录，期望按创建的池容量独立计算，不调用生产重编号函数。

Apple M5 Pro / macOS 27.0：`DM_NVN_ENC_THREAD=0` 与 `1` 各通过 **958 条断言、13 次提交**：

- 首池与非首池，纹理/采样器基址不同，多命令缓冲独立状态；
- 录制期间源页 `PROT_NONE`，结束录制后写入真实句柄并提交；
- 录制后换池、变更源、重复提交，源数组不被修改；
- 零纹理号、零采样器号、全零句柄；`n=0`、`n=32` 及最后一个 combined 槽 127；
- 普通立即绑定保留原快照；CallCommands / CopyCommands 保留子记录的延迟源与池基址。

无游戏进程的测试没有 `main.npdm` 和程序号，完整宿主 bootstrap 会报告这些缺项；不能将该测试称为游戏零红或到达 MARK。

## 真实 GPU 采样与旧实现反证

另以同一完整生产库运行私有集成实验。输入为仓库 `launchers/macos/Branding/AppIcon-1024.png`，以及自有节奏天国的原始顶点/片段着色器，经既有链 `c407c4b309b7` 翻译的库和反射。原始 shader、反射及其哈希接线未被修改；实验调用真实 ProgramSetShaders、DrawArrays、QueueFinish 和 TextureReadTexels，不注入渲染器内部状态。

两组描述符池复用相同本地编号：第二组纹理基址 512、采样器基址 768。纹理分别用真实图标及其逐行反转像素；采样器分别为 clamp 和 repeat，UV 超出 0–1，故错误的纹理或采样器池都会改变可读回结果。每张输出为 64×64 RGBA8，独立 CPU 期望来自输入像素。

| 检查 | 旧基线 `ece9f23a` | 修复后，编码线程 0 / 1 各一次 |
|---|---|---|
| 普通单纹理绑定，第二池 | 0 / 16,384 字节不同 | 均 0 / 16,384 |
| 延迟绑定，录制后变更句柄 | **10,099 / 16,384 字节不同**，首错偏移 1,604，实际 0、期望 5，退出 1 | 均 0 / 16,384 |
| 同一命令改源后重提交 | 前项失败即停止 | 均 0 / 16,384 |
| 源值不变再次提交 | 前项失败即停止 | 均 0 / 16,384 |

旧库由完整恢复到基线的三个生产文件重新构建，`git diff --exit-code ece9f23a -- <三个文件>` 为空；同一夹具对象、宿主对象、输入和 shader，只替换 NVN 静态库。旧库独立保留，未用人为错误输出代替反证。

这是离屏 API/GPU 实验。没有游戏程序号，库的游戏标识检查、常量裁剪表与预热清单还会报告夹具环境缺项，原始日志保留，不能写成完整游戏零红。没有 Mac 游戏同场景、iPhone、帧率或能耗结论；九款回归由维护方执行。

原始证据在本地忽略目录 `build/deferred/`：`test-e-build.log`、`gpu_sample.m`、`gpu-final.log`、`gpu-worker.log`、`baseline-build.log`、`gpu-baseline.log`。游戏文件、着色器二进制与私有路径不入 PR。
