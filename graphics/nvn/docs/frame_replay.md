# 帧录放

改画面、满屏或每笔开销时，不进游戏、不导航：在 Mac 局里录下一帧，之后每次改动都用本树编出的宿主回放这一帧，出截图、满屏判据和每笔指令数。实现在 `graphics/nvn/gfx/nvn/nvn_frame_rec.inc`。

## 录

起 Mac 局时加 `S2A_FRAME_REC`，两种写法：

| 写法 | 录哪一帧 |
|---|---|
| `S2A_FRAME_REC=<目录>` | 自动玩家实时通道（`S2A_AP_LIVE`）里写一行 `REC:<名>`，下一次出图录成 `<目录>/<名>/` |
| `S2A_FRAME_REC=1290,2070:<目录>` | 第 1290、2070 次出图分别录成 `<目录>/f1290/`、`<目录>/f2070/` |
| `S2A_FRAME_REC=<目录>` + `S2A_FRAME_REC_RED=1` | 满屏判据前 3 次判红，各把下一次出图录成 `<目录>/fitred<k>/`（红段落在哪次出图每局不同，定帧录不准）；写 `黑带` / `接缝` / `暗带` 只录这一种内容红 |

录的是「上一次出图到这次出图」之间的全部提交，加上这次出图时的状态：

| 文件 | 内容 |
|---|---|
| `mem.bin` | 游戏地址窗口里有内容的页（全零页不存）：贴图 / 程序 / 同步对象、命令内存、内存池、描述符池都在游戏内存里 |
| `state.bin` | 回放层自己的表：内存池、活着的贴图、CPU 写过的贴图、贴图 / 采样器登记、交换链贴图、深度模式 / 原点 |
| `progkeys.bin` | 每个程序各阶段的着色器键：只在 `nvnProgramSetShaders` 那一刻算得出（之后控制段可能被游戏释放），回放原样放回 |
| `gpu.bin` | GPU 私有贴图（渲染目标、着色器写过的）的内容 |
| `subs.bin` | 本帧每次提交的命令句柄，出图贴图、间隔、裁剪框 |
| `manifest.tsv` | 窗口基址、屏幕宽高、宽屏标志、程序号、链号 |

录像含游戏数据：只放本机仓库外（约定 `~/.s2arm/run/s2arm/frame_rec/<款>/`），不进仓库、不外发。
`frame_rec` 是指向工作盘（上限表 `env/layout.env` 的 `S2A_WORK`）下 `frame_rec` 的软链（11-05 起；之前录在内置盘的留在 `run/s2arm/frame_rec.local/<款>`，工作盘那边有同名软链指回去）。录像与回放局目录一律写这里，不在内置盘另建目录。
回收：整款闲置超过 24 小时自动回收（工作盘由清理器 `WORK_IDLE_DIRS`，内置盘旧录像由 `tools/gc.sh`）。要长留就在工作盘钉住表（`$S2A_WORK/pins`）写一行「`<款目录路径><TAB><原因>`」，没写原因的钉不认。

## 放

```bash
bash tools/frame_replay.sh mk8d ~/.s2arm/run/s2arm/frame_rec/mk8d/f1295
```

宿主占好地址窗口后不装游戏，把游戏内存映射回原地址，按 `state.bin` 调回放层同一组登记函数，把这一帧执行 `S2A_FRAME_REPLAY_N` 遍（缺省 3）。第一遍之后，把 GPU 私有贴图中尺寸、格式都对得上的内容写回去。最后一遍抓上屏图：

- 存 `<输出>/shots/replay.png`；
- 跑满屏判据，红行与局里相同，红帧另存 `fit_red_<k>.png`；
- 每遍打一行：渲染遍数、绘制笔数、提交线程每笔指令数。

前提：

- 地址窗口基址与录时相同（同一台机、同一个宿主布局）。不同就报红退出。
- 链号与录时相同，否则着色器库按本宿主的链号找。
- 库里没有、录时由同局现编的着色器（录时的 `DM_MSL_FALLBACK`，缺省 `<文档根>/wire/<程序号>/shaders`；文档根 = `S2A_DOCS`，Mac 局是局目录。录像清单记下「录时_兜底目录」，回放按它找回，旧录像没这一行按回放的文档根）：程序是从录像放回的，不经 `ProgramSetShaders` 登记，缺键时按兜底目录里同链同指纹的 `<键>_b.json` 阶段复用（`dm_shader_reuse`）。录像那台机上没跑过这款就缺，画面少那几笔并报红「not in the shader map」（11-02 马里奥和索尼克回放缺 66 个键、181 笔不画）。

## 不覆盖的

- **Vulkan 前端（`hle_vk.m`，超级马力欧银河 1 / 2）**：自己编码 Metal，不经 NVN 回放层，录时报红。
- **远端别名区里的内存池**：影子不在游戏地址上，录时报红。
- **深度模板、多重采样、压缩、单张超过 256 MB 的 GPU 贴图**：不存内容，回放靠重画。帧里先读后写的这几类会和录时不同。

## 逐笔定位（回放里用）

| 开关 | 作用 |
|---|---|
| `DM_NVN_DRAWLOG=1 DM_NVN_DRAW_MAX=100000` | 每笔打一行：笔号、顶点 / 片元着色器键、目标 0 的序号尺寸格式、混合状态 |
| `DM_NVN_DRAW_SKIP=a-b` | 跳过本帧第 a 到 b 笔：按区间二分「跳过后某区域变不变」，几秒一步 |
| `DM_NVN_DRAW_MAX=n` | 只画前 n 笔 |
| `DM_NVN_VCAP=n` | 捕获本帧第 n 笔的顶点：这笔照常画之前，用它顶点着色器的捕获入口（`main0_gs`，几何模拟同一个）在同样的顶点缓冲 / 参数 / 实例上跑一遍，等 GPU 完成后写 `<输出目录>/vcap_f<帧>_d<n>.tsv`：每顶点一行裁剪坐标 xyzw 与 x/w、y/w（宽屏外推之前），末行附这笔的外推参数。间接绘制、没有捕获入口的顶点着色器打红线跳过，原绘制不受影响 |

从最终画面倒推某一笔的几何容易被后面的笔干扰（11-01 植物大战僵尸协议页：左侧带的亮侧饰其实是第 29 笔在画布外画的，被误当成第 11 笔推满了），要几何事实就用 `DM_NVN_VCAP` 直接取顶点。

画面错的像素不是某一笔画上去的（多笔共同读同一份坏数据）时，二分会不收敛：改看那些笔共同绑的贴图（`DM_NVN_PASSDUMP_ALL`），再扫录像 `gpu.bin` 里的 Inf / NaN。双人成行黑圆盘（11-01）就是这样定到反射立方体数组的。
